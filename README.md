Pharmacy Order Management 💊
A modern Android application engineered to manage and track daily pharmacy orders with real-time cloud synchronization. The app features a premium user interface with fluid animations, dynamic theme switching, and an intelligent branding adaptation system.

✨ Key Features
Smart Order Tracking: Categorize orders by priority (Urgent, Shortages, Normal) and time (AM/PM) with smooth ValueAnimator color transitions.

Dynamic Branding Engine: Automatically adapts logos, watermarks, and scaling based on the registered pharmacy (e.g., legacy Al-Yosr branding vs. Generic setups).

Premium UI/UX: Built on Material Design 3, featuring custom color state lists, fluid fragment transitions, button scale animators, and modern WindowInsetsCompat for seamless keyboard handling.

Theme Switching: Full Dark/Light mode support with high-contrast custom Material Switches and zero-delay crossfade transitions.

Interactive Data: Direct integration with Android intents for one-click phone dialing and Google Maps navigation via stored location URIs.

Cloud Sync: Real-time data persistence and authentication powered by Firebase, with local caching via SharedPreferences.

🛠 Tech Stack & Libraries
Language: Kotlin

Environment: Android Studio

Backend: Firebase (Authentication & Realtime Database)

UI Framework: Android Native (XML Views)

Components: Material Design Components (MDC)

Animations: ValueAnimator, ArgbEvaluator, Android Transition Framework

📱 Interface Highlights
Auth Screens: Minimalist, card-based login/signup flows with custom focus-aware vector icons (e.g., dynamically toggling lock to lock_open on click).

Bottom Navigation: Smooth routing between "New Order", "Orders List", and "Archive" with dynamic visibility that hides the navigation bar when the keyboard is active.

Pharmacy Details: A dedicated settings hub allowing users to update contact details, embed Google Maps links, and toggle application-wide themes.
